Estes são os atalhos padrão do próprio VS Code: o SCS IntelliSense responde a eles nos
arquivos `.sii` e `.sui`. No Linux são os mesmos do Windows, exceto onde indicado.
Para mudar qualquer um, abra **Keyboard Shortcuts** com :kbd[Ctrl + K] e depois
:kbd[Ctrl + S] (:kbd[⌘ + K] e depois :kbd[⌘ + S] no macOS).

## Escrevendo

| Ação | Windows / Linux | macOS | Página |
| :--- | :-------------- | :---- | :----- |
| Abrir as sugestões | :kbd[Ctrl + Space] | :kbd[⌃ + Space] | [Autocompletar](../02-features/completion.mdx) |
| Mostrar a descrição do que está sob o cursor | :kbd[Ctrl + K] e depois :kbd[Ctrl + I] | :kbd[⌘ + K] e depois :kbd[⌘ + I] | [Hover](../02-features/completion.mdx#hover) |
| Formatar o arquivo | :kbd[Shift + Alt + F] (Linux: :kbd[Ctrl + Shift + I]) | :kbd[⇧ + ⌥ + F] | [Formatador](../02-features/formatter.mdx) |
| Formatar a seleção | :kbd[Ctrl + K] e depois :kbd[Ctrl + F] | :kbd[⌘ + K] e depois :kbd[⌘ + F] | [Formatador](../02-features/formatter.mdx#formatar-um-arquivo) |
