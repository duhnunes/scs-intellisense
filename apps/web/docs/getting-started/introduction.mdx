SCS IntelliSense is a Visual Studio Code extension for modding **American Truck
Simulator** and **Euro Truck Simulator 2**. It understands the game's definition
files (`.sii` and `.sui`) and helps you write them the way you would write code
in any modern editor: with colors, error checks, suggestions and navigation.

## What it does

- **Colors by meaning.** Class names, unit names, attribute keys, values and
  comments each get their own color, so a file is easier to read.
  See [Highlighting and icons](../features/highlighting.mdx).
- **Finds mistakes while you type.** A missing `:` or `}`, an invalid unit name,
  two units with the same name, or a misspelled attribute such as `prcie`
  instead of `price`. Most problems come with a one-click fix.
  See [Diagnostics and quick fixes](../features/diagnostics.mdx).
- **Suggests what comes next.** Class names, attribute keys, the values an
  attribute accepts, units to point to, and the files of your mod.
  See [Completion and hover](../features/completion.mdx).
- **Lets you jump around your mod.** Ctrl+click a unit name to open where it's
  defined, list everything that uses it, or rename it everywhere at once.
  See [Navigation](../features/navigation.mdx).
- **Keeps paths working.** Rename or move a file in VS Code and every path that
  points to it is updated for you.
  See [Moving and renaming files](../features/moving-files.mdx).
- **Formats your files.** Consistent indentation, braces and spacing, without
  ever changing a value. See [Formatter](../features/formatter.mdx).

## Tested on the game's own files

Every check is tested against the files the game itself ships with: 73,224 `.sii`/`.sui` files of American Truck Simulator 1.61, the base game and
56 DLCs. None of them is reported as broken, so when the extension tells you
something is wrong in your mod, it's worth a look.

Euro Truck Simulator 2 uses the same engine and the same file format, but it
hasn't been tested on its files yet. If you mod ETS2 and something looks wrong,
please [report it](../help/reporting-issues.mdx).
