---
title: Keyboard shortcuts
description: The VS Code shortcuts that use SCS IntelliSense, on one page.
order: 3
---

These are VS Code's own default shortcuts: SCS IntelliSense answers them for
`.sii` and `.sui` files. On Linux they're the same as on Windows, except where
noted. To change any of them, open **Keyboard Shortcuts** with :kbd[Ctrl + K] then :kbd[Ctrl + S]
(:kbd[⌘ + K] then :kbd[⌘ + S] on macOS).

## Writing

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Open suggestions | :kbd[Ctrl + Space] | :kbd[⌃ + Space] | [Completion](../02-features/completion.mdx) |
| Show the description of what's under the cursor | :kbd[Ctrl + K] then :kbd[Ctrl + I] | :kbd[⌘ + K] then :kbd[⌘ + I] | [Hover](../02-features/completion.mdx#hover) |
| Format the file | :kbd[Shift + Alt + F] (Linux: :kbd[Ctrl + Shift + I]) | :kbd[⇧ + ⌥ + F] | [Formatter](../02-features/formatter.mdx) |
| Format the selection | :kbd[Ctrl + K] then :kbd[Ctrl + F] | :kbd[⌘ + K] then :kbd[⌘ + F] | [Formatter](../02-features/formatter.mdx#format-a-file) |

## Fixing problems

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Show the quick fixes | :kbd[Ctrl + .] | :kbd[⌘ + .] | [Quick fixes](../02-features/diagnostics.mdx#quick-fixes) |
| Apply the only quick fix | :kbd[Shift + Alt + .] | :kbd[⌥ + ⇧ + .] | [Quick fixes](../02-features/diagnostics.mdx#quick-fixes) |
| Go to the next problem | :kbd[F8] | :kbd[F8] | [Diagnostics](../02-features/diagnostics.mdx) |
| Go to the previous problem | :kbd[Shift + F8] | :kbd[⇧ + F8] | [Diagnostics](../02-features/diagnostics.mdx) |
| Open the Problems panel | :kbd[Ctrl + Shift + M] | :kbd[⇧ + ⌘ + M] | [Diagnostics](../02-features/diagnostics.mdx) |

## Moving around

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Go to a unit's definition, or open a path's file | :kbd[Ctrl] + click | :kbd[⌘] + click | [Navigation](../02-features/navigation.mdx) |
| Go to Definition | :kbd[F12] | :kbd[F12] | [Navigation](../02-features/navigation.mdx#go-to-definition) |
| Peek the definition without leaving the file | :kbd[Alt + F12] | :kbd[⌥ + F12] | [Navigation](../02-features/navigation.mdx#go-to-definition) |
| List what points to a unit, or uses a file | :kbd[Shift + F12] | :kbd[⇧ + F12] | [Navigation](../02-features/navigation.mdx#find-references) |
| The same list, in a side panel | :kbd[Shift + Alt + F12] | :kbd[⌥ + ⇧ + F12] | [Navigation](../02-features/navigation.mdx#find-references) |
| Jump to a unit of the current file | :kbd[Ctrl + Shift + O] | :kbd[⇧ + ⌘ + O] | [Navigation](../02-features/navigation.mdx#outline-and-breadcrumbs) |
| Go back to where you were | :kbd[Alt + ←] (Linux: :kbd[Ctrl + Alt + -]) | :kbd[⌃ + -] | |

## Renaming

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Rename a unit everywhere | :kbd[F2] | :kbd[F2] | [Navigation](../02-features/navigation.mdx#rename-a-unit) |
| Rename a file or folder in the Explorer | :kbd[F2] | :kbd[Enter] | [Moving and renaming files](../02-features/moving-files.mdx) |
| Undo a move, with its path updates | :kbd[Ctrl + Z] | :kbd[⌘ + Z] | [Moving and renaming files](../02-features/moving-files.mdx#review-the-changes) |

| Settings | :kbd[Ctrl + ,] | :kbd[⌘ + ,] |
| Extensions view | :kbd[Ctrl + Shift + X] | :kbd[⇧ + ⌘ + X] |
