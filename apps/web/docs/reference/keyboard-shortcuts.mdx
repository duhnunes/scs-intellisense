title: Keyboard shortcuts
description: The VS Code shortcuts that use SCS IntelliSense, on one page.

These are VS Code's own default shortcuts: SCS IntelliSense answers them for
`.sii` and `.sui` files. On Linux they're the same as on Windows, except where
noted. To change any of them, open **Keyboard Shortcuts** with `Ctrl+K Ctrl+S`
(`⌘K ⌘S` on macOS).

## Writing

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Open suggestions | `Ctrl+Space` | `⌃Space` | [Completion](../features/completion.mdx) |
| Show the description of what's under the cursor | `Ctrl+K Ctrl+I` | `⌘K ⌘I` | [Hover](../features/completion.mdx#hover) |
| Format the file | `Shift+Alt+F` (Linux: `Ctrl+Shift+I`) | `⇧⌥F` | [Formatter](../features/formatter.mdx) |
| Format the selection | `Ctrl+K Ctrl+F` | `⌘K ⌘F` | [Formatter](../features/formatter.mdx#format-a-file) |

## Fixing problems

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Show the quick fixes | `Ctrl+.` | `⌘.` | [Quick fixes](../features/diagnostics.mdx#quick-fixes) |
| Apply the only quick fix | `Shift+Alt+.` | `⌥⇧.` | [Quick fixes](../features/diagnostics.mdx#quick-fixes) |
| Go to the next problem | `F8` | `F8` | [Diagnostics](../features/diagnostics.mdx) |
| Go to the previous problem | `Shift+F8` | `⇧F8` | [Diagnostics](../features/diagnostics.mdx) |
| Open the Problems panel | `Ctrl+Shift+M` | `⇧⌘M` | [Diagnostics](../features/diagnostics.mdx) |

## Moving around

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Go to a unit's definition, or open a path's file | `Ctrl+click` | `⌘+click` | [Navigation](../features/navigation.mdx) |
| Go to Definition | `F12` | `F12` | [Navigation](../features/navigation.mdx#go-to-definition) |
| Peek the definition without leaving the file | `Alt+F12` | `⌥F12` | [Navigation](../features/navigation.mdx#go-to-definition) |
| List what points to a unit, or uses a file | `Shift+F12` | `⇧F12` | [Navigation](../features/navigation.mdx#find-references) |
| The same list, in a side panel | `Shift+Alt+F12` | `⌥⇧F12` | [Navigation](../features/navigation.mdx#find-references) |
| Jump to a unit of the current file | `Ctrl+Shift+O` | `⇧⌘O` | [Navigation](../features/navigation.mdx#outline-and-breadcrumbs) |
| Go back to where you were | `Alt+←` (Linux: `Ctrl+Alt+-`) | `⌃-` | |

## Renaming

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Rename a unit everywhere | `F2` | `F2` | [Navigation](../features/navigation.mdx#rename-a-unit) |
| Rename a file or folder in the Explorer | `F2` | `Enter` | [Moving and renaming files](../features/moving-files.mdx) |
| Undo a move, with its path updates | `Ctrl+Z` | `⌘Z` | [Moving and renaming files](../features/moving-files.mdx#review-the-changes) |

## Everything else

| Action | Windows / Linux | macOS |
| :----- | :-------------- | :---- |
| Command Palette (every **SCS IntelliSense** command) | `Ctrl+Shift+P` | `⇧⌘P` |
| Settings | `Ctrl+,` | `⌘,` |
| Extensions view | `Ctrl+Shift+X` | `⇧⌘X` |
