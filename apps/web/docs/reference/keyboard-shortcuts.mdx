---
title: Keyboard shortcuts
description: The VS Code shortcuts that use SCS IntelliSense, on one page.
link_position: 3
---

These are VS Code's own default shortcuts: SCS IntelliSense answers them for
`.sii` and `.sui` files. On Linux they're the same as on Windows, except where
noted. To change any of them, open **Keyboard Shortcuts** with <KbdGroup aria-label="Ctrl plus K, then Ctrl plus S"><Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> <Kbd>Ctrl</Kbd>+<Kbd>S</Kbd></KbdGroup>
(<KbdGroup aria-label="Command plus K, then Command plus S"><Kbd>⌘</Kbd><Kbd>K</Kbd> <Kbd>⌘</Kbd><Kbd>S</Kbd></KbdGroup> on macOS).

## Writing

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Open suggestions | <KbdGroup aria-label="Ctrl plus Space"><Kbd>Ctrl</Kbd>+<Kbd>Space</Kbd></KbdGroup> | <KbdGroup aria-label="Control plus Space"><Kbd>⌃</Kbd><Kbd>Space</Kbd></KbdGroup> | [Completion](../features/completion.mdx) |
| Show the description of what's under the cursor | <KbdGroup aria-label="Ctrl plus K, then Ctrl plus I"><Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> <Kbd>Ctrl</Kbd>+<Kbd>I</Kbd></KbdGroup> | <KbdGroup aria-label="Command plus K, then Command plus I"><Kbd>⌘</Kbd><Kbd>K</Kbd> <Kbd>⌘</Kbd><Kbd>I</Kbd></KbdGroup> | [Hover](../features/completion.mdx#hover) |
| Format the file | <KbdGroup aria-label="Shift plus Alt plus F"><Kbd>Shift</Kbd>+<Kbd>Alt</Kbd>+<Kbd>F</Kbd></KbdGroup> (Linux: <KbdGroup aria-label="Ctrl plus Shift plus I"><Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>I</Kbd></KbdGroup>) | <KbdGroup aria-label="Shift plus Option plus F"><Kbd>⇧</Kbd><Kbd>⌥</Kbd><Kbd>F</Kbd></KbdGroup> | [Formatter](../features/formatter.mdx) |
| Format the selection | <KbdGroup aria-label="Ctrl plus K, then Ctrl plus F"><Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> <Kbd>Ctrl</Kbd>+<Kbd>F</Kbd></KbdGroup> | <KbdGroup aria-label="Command plus K, then Command plus F"><Kbd>⌘</Kbd><Kbd>K</Kbd> <Kbd>⌘</Kbd><Kbd>F</Kbd></KbdGroup> | [Formatter](../features/formatter.mdx#format-a-file) |
