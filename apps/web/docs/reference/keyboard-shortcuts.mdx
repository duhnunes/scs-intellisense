---
title: Keyboard shortcuts
description: The VS Code shortcuts that use SCS IntelliSense, on one page.
link_position: 3
---

These are VS Code's own default shortcuts: SCS IntelliSense answers them for
`.sii` and `.sui` files. On Linux they're the same as on Windows, except where
noted. To change any of them, open **Keyboard Shortcuts** with :kbd[Ctrl] + :kbd[K] then :kbd[Ctrl] + :kbd[S]
(:kbd[⌘] :kbd[K] then :kbd[⌘] :kbd[S] on macOS).

## Writing

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Open suggestions | :kbd[Ctrl] + :kbd[Space] | :kbd[⌃] :kbd[Space] | [Completion](../features/completion.mdx) |
| Show the description of what's under the cursor | :kbd[Ctrl] + :kbd[K] then :kbd[Ctrl] + :kbd[I] | :kbd[⌘] :kbd[K] then :kbd[⌘] :kbd[I] | [Hover](../features/completion.mdx#hover) |
| Format the file | :kbd[Shift] + :kbd[Alt] + :kbd[F] (Linux: :kbd[Ctrl] + :kbd[Shift] + :kbd[I]) | :kbd[⇧] :kbd[⌥] :kbd[F] | [Formatter](../features/formatter.mdx) |
| Format the selection | :kbd[Ctrl] + :kbd[K] then :kbd[Ctrl] + :kbd[F] | :kbd[⌘] :kbd[K] then :kbd[⌘] :kbd[F] | [Formatter](../features/formatter.mdx#format-a-file) |

## Fixing problems

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Show the quick fixes | :kbd[Ctrl] + :kbd[.] | :kbd[⌘] :kbd[.] | [Quick fixes](../features/diagnostics.mdx#quick-fixes) |
| Apply the only quick fix | :kbd[Shift] + :kbd[Alt] + :kbd[.] | :kbd[⌥] :kbd[⇧] :kbd[.] | [Quick fixes](../features/diagnostics.mdx#quick-fixes) |
| Go to the next problem | :kbd[F8] | :kbd[F8] | [Diagnostics](../features/diagnostics.mdx) |
| Go to the previous problem | :kbd[Shift] + :kbd[F8] | :kbd[⇧] :kbd[F8] | [Diagnostics](../features/diagnostics.mdx) |
| Open the Problems panel | :kbd[Ctrl] + :kbd[Shift] + :kbd[M] | :kbd[⇧] :kbd[⌘] :kbd[M] | [Diagnostics](../features/diagnostics.mdx) |

## Moving around

| Action | Windows / Linux | macOS | Page |
| :----- | :-------------- | :---- | :--- |
| Go to a unit's definition, or open a path's file | :kbd[Ctrl] + click | :kbd[⌘] + click | [Navigation](../features/navigation.mdx) |
| Go to Definition | :kbd[F12] | :kbd[F12] | [Navigation](../features/navigation.mdx#go-to-definition) |
| Peek the definition without leaving the file | :kbd[Alt] + :kbd[F12] | :kbd[⌥] :kbd[F12] | [Navigation](../features/navigation.mdx#go-to-definition) |
| List what points to a unit, or uses a file | :kbd[Shift] + :kbd[F12] | :kbd[⇧] :kbd[F12] | [Navigation](../features/navigation.mdx#find-references) |
| The same list, in a side panel | :kbd[Shift] + :kbd[Alt] + :kbd[F12] | :kbd[⌥] :kbd[⇧] :kbd[F12] | [Navigation](../features/navigation.mdx#find-references) |
| Jump to a unit of the current file | :kbd[Ctrl] + :kbd[Shift] + :kbd[O] | :kbd[⇧] :kbd[⌘] :kbd[O] | [Navigation](../features/navigation.mdx#outline-and-breadcrumbs) |
| Go back to where you were | :kbd[Alt] + :kbd[←] (Linux: :kbd[Ctrl] + :kbd[Alt] + :kbd[-]) | :kbd[⌃] :kbd[-] | |

| :----- | :-------------- | :---- | :--- |
