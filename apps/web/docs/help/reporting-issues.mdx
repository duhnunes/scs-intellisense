Found a bug, a wrong warning, or a suggestion that makes no sense? Reports from
real mods are what make the extension better, and what lets the experimental
features become stable.

## Before you report

1. Run **SCS IntelliSense: Copy Bug Report Info** from the Command Palette
   (<KbdGroup aria-label="Ctrl plus Shift plus P"><Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd></KbdGroup>). It copies your extension and VS Code versions, your settings
   and the recent log.
2. If the problem is about a specific file, keep a short piece of it that shows the
   problem.

The log can include the names of files and folders on your computer. Read it before
you share it.

## Where to report

| Problem | Where |
| :------ | :---- |
| The extension: a wrong error, a crash, a feature that doesn't work | [SCS IntelliSense issues](https://github.com/duhnunes/scs-intellisense/issues) |
| A class or an attribute missing, a wrong type or description | [scs-schema issues](https://github.com/duhnunes/scs-schema/issues) |

## A good report has

- **What you did**: the steps to see the problem.
- **What you expected**, and **what happened** instead.
- **The bug report info** you copied.
- **A piece of the file**, in a code block, if the problem is in one.

If you mod Euro Truck Simulator 2, mention it: the extension is tested mostly on
American Truck Simulator files.
